# Scratch panels and MAS PINs

Triggers: scratch pin, scratch, pin, shortcode, sms, 34488, mas, verification code

A PIN needs its shortcode: read both from the message, the photo note,
or history before calling verify_pin. With no provider connected, give
the SMS route (text the PIN to the printed shortcode) and offer to read
the reply. Quote a provider reply as that provider's statement about
the PIN — it speaks for the code, never for the pack contents.
