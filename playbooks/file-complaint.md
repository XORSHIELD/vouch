# Reports and complaints

Triggers: report, seller, complaint, fccpc, demand, refund, nafdac report, escalate, open a case

High-risk signals point to a NAFDAC report, expired packs to a refund
plus a regulator report, seller disputes to a seller demand, consumer
complaints to the FCCPC. Run a check first, then preview_document the
matching draft. Ask only for missing facts — seller, location, price,
receipt. Cases open only on the user's confirmation.
